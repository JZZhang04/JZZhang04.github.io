# Jiazuo Zhang Portfolio

This is a personal portfolio site for presenting my software engineering background, technical skills, experience, education, and selected projects.

The site is built with React, TypeScript, Vite, CSS, and React Flow.

## Visit

Open the live site here:

https://jzzhang04.github.io

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## Build

Create a production build:

```bash
npm run build
```
